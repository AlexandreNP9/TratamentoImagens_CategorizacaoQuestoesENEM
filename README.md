# Olá, seja bem-vindo(a) ao meu repositório!

Aqui na ```main``` tem apenas esse README e o LICENSE.  

A branch ```generico-para-todas-provas``` contém os códigos genéricos para serem adaptados ao caderno do ENEM que você for recortar.  

A branch ```2024-dia1-caderno1-azul-regular``` serve de exemplo aplicado com o respectivo caderno de seu nome.  

# Objetivo
Este repositório é para aprender a tratar as imagens dos cadernos de questões do ENEM.  
O objetivo desta fase é ter uma questão por imagem, com o devido nome.  

# Algumas situações para você considerar:  
Tenha em mente de que as imagens que você preparar aqui serão utilizadas em fases futuras desse projeto de Categorização das Questões do ENEM. Por isso, faça de maneira PERFEITA!  

Tem casos em que várias questões são baseadas em um mesmo texto base. Será que é interessante manter o texto base em cada uma das perguntas? Pense sobre isso...  

Adote uma postura de dono(a) do negócio, faça de forma EXCELENTE!

# Fase 1 de 5  
Esta fase faz parte de um projeto de categorização das questões do ENEM de acordo com a matriz de referência, composto pelas seguintes fases:  
1) Tratamento das imagens das questões  
2) Extração do conteúdo usando OCR  
3) Análise das questões usando LLM com o conteúdo das questões, gabarito e matriz de referência  
4) Alimentação de um banco de dados  
5) Interface para o usuário final
